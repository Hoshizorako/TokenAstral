TokenAstral enables real-time data processing and AI-driven insights through a cloud-based Analytics Platform and Processing Engine.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenAstral.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure TokenAstral, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
